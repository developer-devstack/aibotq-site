01 — Build

Agents as plain TypeScript.

Define models, tools and memory in one file. Aibotq handles streaming, retries and state so you can focus on behaviour.

agent.ts
import { agent, tool } from 'aibotq'

export default agent({
  model: 'gpt-4o',
  tools: [search, weather],
  stream: true
})

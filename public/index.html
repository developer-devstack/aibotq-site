01 — Push

Your git history is the deploy button.

Import once and Aibotq registers a webhook on the repository. Push to the default branch for production; open a pull request for a preview deployment. Fork PRs are ignored so untrusted code never meets your env vars.

How webhooks work →

~/my-agent — zsh
$ git checkout -b feature
$ git push -u origin feature
# open a pull request → preview deployment
$ git merge feature && git push
# push to main → production deployment
$  
02 — Protect

Built to keep keys off the wire.

Sessions are HttpOnly cookies, the OAuth state is signed, POSTs are origin-checked and auth/deploy endpoints are rate-limited. Environment variables are encrypted at rest and only their names ever come back.
